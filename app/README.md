# 한국사 OX 학습 퀴즈 (다편 구조)

한국사를 **시대별 OX 퀴즈**로 학습하는 독립 실행 정적 사이트입니다. 프레임워크·빌드 도구 없이 바닐라 JS로만 동작합니다.

**▶ 바로 풀기: https://aicatveo3-prog.github.io/history-quiz-study/**

## 실행 방법

별도 설치가 필요 없습니다. `index.html`을 브라우저로 열기만 하면 됩니다.

- 파일을 더블클릭하거나
- 간단한 로컬 서버로 열어도 됩니다:
  ```
  cd app
  python3 -m http.server 8000
  # http://localhost:8000 접속
  ```

GitHub Pages 등 정적 호스팅에 `app/` 폴더를 그대로 올려도 동작합니다.

## 구성

### 앱 코드

| 파일 | 역할 |
|------|------|
| `index.html` | 페이지 셸 · 폰트 · 애니메이션/탭 효과 CSS · `ASSET_VER`(캐시 무효화 버전) |
| `app-id.js` | 앱 식별자(`APP_ID`) — 저장소 네임스페이스 기준. 같은 도메인의 다른 퀴즈 앱과 기록이 섞이지 않게 한다 |
| `app.js` | 화면 전환·상태·이론 블록 렌더링 + 오답노트/저장함 로직 (바닐라 JS) |
| `chapters.js` | 챕터 목록 매니페스트 (id·제목·데이터 파일·문항 수) |
| `sync.js` | 로그인(구글·이메일) + 기기 간 동기화 모듈 (선택 기능, 설정 시에만 동작) |
| `firebase-config.js` | 동기화 설정 — 설정 방법은 파일 상단 주석 참고 |

## 기능

- **홈(챕터 목록) → 목차(파트) → 퀴즈 → 결과** 흐름 — 챕터 데이터는 카드 탭 시 지연 로딩
- 총 1,716문항 O/X 풀이 — 답 선택 즉시 정답/해설 표시
- 기출 선지 원문 문항 + 핵심 단어를 바꾼 변형 문항을 짝으로 구성 (편·파트별 O/X 비율 5:5 근접, 같은 정답 4연속 없음)
- **🏅 한능검 기출 뱃지** — **그 논점이 실제로 출제된 회차**를 표시합니다. 5지선다를 OX로 변형한 것이므로 문장이 시험지와 토씨까지 같지는 않지만, 다루는 논점은 그 회차에 나온 것입니다. 여러 회차에 걸친 논점은 **"N회 출제" 빈출 뱃지**가 함께 붙습니다. 한능검 **제62~78회 심화 17회분**을 시대별로 분산 반영해 730문항에 뱃지가 있습니다.
  - 정답 선지는 ⭕ 문항, 오답 선지는 **원 문제의 주어를 유지한 ❌ 문항**에 뱃지를 답니다. 예를 들어 부여를 묻는 문제의 오답 선지 "천군과 소도가 존재하였다"는 `부여에는 … 소도가 존재하였다` ❌ 문항이 됩니다. 한쪽으로 쏠리면 기출만 보기에서 답이 예측되므로 ⭕:❌ 균형을 맞춥니다(현재 **361:369**, ⭕ 49.5%).
  - 짝이 없던 기출 ⭕에는 대응하는 ❌ 변형을 만들어 뱃지를 옮겼습니다. **원래 ⭕ 문항은 지문 그대로 남고 뱃지만 내려놓으므로 기출 진술을 잃지 않습니다.** 변형은 기출 원문 뒤쪽 단어(주체·연도·기구명·지역·수치·포함↔제외)를 **제자리에서 바꾸는 방식**이라 원문과 길이가 비슷합니다 — 길이·어투로 정답이 드러나지 않게 하기 위함입니다.
- **🏅 한능검 기출만 보기** — 전역 ON/OFF 토글. 켜면 기출 논점 문항만 골라 풉니다.
- 파트별 **이론 정리** 패널(섹션·표·트리·🎯/📎/🔑 콜아웃) — ON/OFF 토글 상태는 브라우저에 저장(`localStorage`)
- 편별 이론 전체를 퀴즈 파트 구조에 맞춰 재구성 — 각 파트 끝에 🎯 함정 체크, 필요 시 📎 심화·참고 박스
- **⭐ 최종 암기 체크리스트** — 편별 전용 화면(파트 목록 상단 카드). 항목마다 ⭕정답/❌함정 대비 표시, 탭하면 암기 완료 체크. 진행 기록·체크 상태는 챕터별 `localStorage` 키에 저장
- **📌 복습 노트 (오답노트 · 저장함)** — 홈 상단 카드로 진입. 전 챕터 공통
  - **오답노트**: 문제를 틀리면 자동으로 쌓입니다(본문·정답·해설 스냅샷 저장). "이 문제들 풀기"로 오답만 다시 풀 수 있고, 복습 중 정답을 맞히면 오답노트에서 자동 제거됩니다.
  - **저장함(북마크)**: 문제 옆 ☆ 버튼으로 맞은 문제·틀린 문제 모두 저장할 수 있고, 저장함에서 모아 다시 풀 수 있습니다.
  - 자료가 수정·재배열돼도 기록이 살아남도록 문항을 본문 해시 id로 식별합니다. 기록은 `localStorage`(`q:hanguksa:wrong`·`q:hanguksa:saved`)에 저장됩니다.
- **☁️ 로그인 동기화 (선택)** — `firebase-config.js`에 Firebase 설정을 넣으면 구글·이메일 로그인이 켜지고, 진도·체크리스트·오답·저장 기록이 클라우드(Firestore)에 백업되어 여러 기기와 동기화됩니다. 설정 전에는 로그인 UI가 숨겨지고 로컬 저장만으로 완전히 동작합니다. 설정 순서는 `firebase-config.js` 상단 주석 참고.

## 저장소 네임스페이스 (앱 여러 개 운영)

퀴즈 앱들이 같은 도메인(GitHub Pages)에 배포되면 `localStorage`를 공유하므로, 모든 키를 `app-id.js`의 `APP_ID`로 격리한다.

| | 경로 |
|---|---|
| localStorage | `q:<APP_ID>:wrong` · `q:<APP_ID>:saved` · `q:<APP_ID>:session:<챕터id>` · `q:<APP_ID>:checklist:<챕터id>` · `q:<APP_ID>:theoryOn` · `q:<APP_ID>:examOnly` · `q:<APP_ID>:lastChapter` |
| Firestore | `users/{uid}/apps/<APP_ID>` |

**새 퀴즈 앱을 만들 때:** `app-id.js`의 `APP_ID`만 새 값으로 바꾸면 저장소가 자동 분리된다. `firebase-config.js`는 그대로 복사한다 — uid는 Firebase 프로젝트 단위로 발급되므로, 프로젝트를 공유해야 구글 계정 하나로 모든 앱에서 같은 사용자로 로그인된다. Firestore 보안 규칙은 `users/{uid}` 하위 전체를 허용하므로 수정할 필요가 없다.

`APP_ID`는 한 번 정하면 바꾸지 않는다 (바꾸면 기존 학습 기록을 찾지 못한다). 네임스페이스 도입(2026-07) 이전의 공용 `jibangse_*` 키는 앱 로드 시 1회 자동 이관되며, 이때 `CHAPTER_LIST`에 있는 챕터의 기록만 가져오므로 다른 앱 기록은 건드리지 않는다.

## 참고

- 본문 글꼴은 Pretendard(CDN)이며, 오프라인에서는 시스템 글꼴로 자연스럽게 대체됩니다.
- 문항은 기출 선지 원문을 유지한 ⭕ 문항과, 앞부분은 옳고 뒷부분에서 틀리도록 핵심 단어(주체·연도·인물·포함/제외 등)를 바꾼 ❌ 변형 문항으로 구성했습니다.
- 새 편 추가·기출 반영 등 작업 표준은 저장소 루트 `CLAUDE.md` 참고.
