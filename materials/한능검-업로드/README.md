# 한능검 자료 업로드 (Grok 생성용)

이 폴더에 **한국사능력검정시험 심화** 자료를 올리면, Grok 4.5가 보고 OX 퀴즈·이론정리·체크리스트를 생성합니다.

기존 Claude/Opus 자료(`materials/한능검/`)와 **분리**되어 있습니다. 작성 규칙은 저장소 루트 `CLAUDE.md`를 따릅니다.

## 올리는 파일 (회차마다 권장 2종)

| 종류 | 파일명 예시 | 내용 |
|------|-------------|------|
| 정답표·시대 배정 | `2026_제79회_심화.txt` 또는 `_정답표.txt` | 문항 번호·정답·시대 배분 |
| 문제 원문 | `2026_제79회_심화_원문추출.txt` 또는 `_원문메모.txt` | 지문·선지 원문 |

PDF를 올려도 되지만, **텍스트(.txt)가 있으면 생성 품질이 훨씬 좋습니다.**

## 업로드 방법

1. 저장소 → `materials/한능검-업로드/`
2. **Add file** → **Upload files**
3. 파일 끌어다 놓고 **main**에 커밋
4. 채팅 예: `Grok 제5편 생성해줘` / `한능검 79회 반영해줘`

## 생성 결과 위치

- 앱 홈 목록 그룹: **Grok 생성** (제1~10편)
- 데이터 파일: `app/quizdata-gk01.js` ~ `quizdata-gk10.js`
